# Tục ngữ · Ca dao — Lô tô Call Cards

100 Vietnamese proverb & folk-verse call cards for lô tô.

## Download

- [tuc-ngu-ca-dao-lotto-cards.pdf](./tuc-ngu-ca-dao-lotto-cards.pdf) — printable deck (Letter, 4 cards/page, 26 pages)

## How to call

1. Hit the number loud (`Một!`, `Hai!`, …)
2. Read the tục ngữ on the `·` beats
3. Punch the **red rhyme word** at the end
4. Roll straight into the next number (the rhyme matches the next call)

## Print

Print Letter size, cut on the card frames. Cover page first, then cards 1–100.
