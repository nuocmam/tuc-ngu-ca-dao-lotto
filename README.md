# Lô tô Call Cards

Printable Vietnamese lô tô call-card decks.

## Downloads

- [tuc-ngu-ca-dao-lotto-cards.pdf](./tuc-ngu-ca-dao-lotto-cards.pdf) — tục ngữ / ca dao deck (Letter, 4 cards/page, 26 pages)
- [bolero-lotto-cards.pdf](./bolero-lotto-cards.pdf) — bolero / nhạc vàng deck (Letter, 4 cards/page, 26 pages)

## Bolero / nhạc vàng notes

- Uses popular **song titles only**
- Call lines are short **original** lô tô chants inspired by the title mood
- **No song lyrics** are included

## How to call

1. Hit the number loud (`Một!`, `Hai!`, …)
2. Read the chant on the `·` beats
3. Punch the **red rhyme word** at the end
4. Roll straight into the next number (the rhyme matches the next call)

## Print

Print Letter size, cut on the card frames. Cover page first, then cards 1–100.
